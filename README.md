# LectureHub Frontend

Это фронтенд часть моей дипломной работы — платформы для онлайн-обучения LectureHub.

## О проекте

LectureHub — это образовательная платформа, которая объединяет преподавателей и студентов в единой среде для проведения лекций, прохождения курсов и оценки знаний.

## Технологический стек

- **React 19** — современная библиотека для построения пользовательского интерфейса
- **Vite** — быстрый сборщик для разработки и продакшена
- **TypeScript** — типобезопасная разработка
- **Tailwind CSS** — утилитарный CSS-фреймворк для стилизации
- **React Router** — маршрутизация в приложении
- **Lucide React** — иконки для интерфейса

## Структура приложения

Приложение разделено на три основные роли пользователей:

### Для гостей
- Главная страница с информацией о платформе
- Авторизация и регистрация
- Восстановление пароля

### Для студентов
- Личный кабинет с дашбордом
- Просмотр доступных курсов
- Прохождение лекций в реальном времени
- Просмотр результатов и статистики
- Редактирование профиля

### Для преподавателей
- Управление курсами и лекциями
- Проведение живых сессий
- Редактор квизов и тестов
- Оценка работ студентов
- Аналитика активности

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск сервера разработки
npm run dev

# Сборка для продакшена
npm run build

# Предпросмотр продакшен-сборки
npm run preview
```

## Структура проекта

```
src/
├── components/
│   ├── layout/      — компоненты макетов для разных ролей
│   └── ui/          — переиспользуемые UI-компоненты
├── pages/
│   ├── guest/       — страницы для неавторизованных пользователей
│   ├── student/     — страницы для студентов
│   └── teacher/     — страницы для преподавателей
├── App.tsx          — главный компонент приложения
├── main.tsx         — точка входа
└── index.css        — глобальные стили
```
